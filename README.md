# micro:bit Sensorwerkstatt

Sechs ausgearbeitete Lernstraßen für die Klassen 7–9:

- LDR (Lichtsensor)
- Potentiometer
- NTC
- PTC
- IR-Modul
- Ultraschallsensor

Enthalten sind realistische Direkt- und Breadboard-Aufbauten, deutsche MakeCode-Blockfolgen, Checkpoints, Verständnisfragen, G/M-Projekte, E-Extras und aufklappbare Lösungen zur Selbstkontrolle.
